# Security Policy

## Reporting a Vulnerability
Please report security vulnerabilities to security@nexusguard.ai.

## Security Measures
- **mTLS**: Enforced via Istio
- **Secrets**: Managed via HashiCorp Vault
- **Policy**: Enforced via OPA (Rego)
- **Scanning**: Trivy, Snyk, CodeQL in CI/CD
- **Compliance**: GDPR, HIPAA, SOC2 ready
